{\bfseries{Doubly linked list}} V2.\+0 is an implementation of popular data structure with some useful features: ~\newline



\begin{DoxyItemize}
\item Dump your data structure in text / png or html file at any moment!
\item Colorful \& intuitive dump files design
\item Debug with comfort!
\end{DoxyItemize}\hypertarget{md_README_autotoc_md3}{}\doxysubsection{\texorpdfstring{Feature list}{Feature list}}\label{md_README_autotoc_md3}

\item Dump to the .txt file supported!
\item Dump to the .png file supported!
\item Dump to the .html file provided (incorporating both .txt and .png files inside!)!
\end{DoxyEnumerate}
