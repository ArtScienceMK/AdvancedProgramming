{\bfseries{Akinator}} V2.\+0 is a chatbot with some interesting features: ~\newline



\begin{DoxyItemize}
\item Guessing any object, you can imagine! If it\textquotesingle{}s not found it will be automatically added!
\item Colorful \& intuitive dump file (choice between text and visual dump is available)
\item Giving a definition to any (known) object!
\item Comparing two objects!
\item Saving (or not) base, you improved by guessing unknown words!
\end{DoxyItemize}\hypertarget{md_README_autotoc_md3}{}\doxysubsection{\texorpdfstring{Feature list}{Feature list}}\label{md_README_autotoc_md3}
